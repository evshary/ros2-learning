Canonical 與 Ubuntu 的資訊分散在不同網站：文件、討論、問題追蹤與套件下載各有入口。
以下整理常用網站，方便依需求查找；這不是完整清單，其中也包含社群維護的網站。

## 官方入口與文件

| 網站 | 主要用途 |
| --- | --- |
| [Canonical](https://canonical.com/) | 查看 Canonical 的產品、服務與公司資訊。 |
| [Ubuntu](https://ubuntu.com/) | Ubuntu 介紹、下載入口，以及桌面、伺服器與其他版本的資訊。 |
| [Ubuntu 文件](https://docs.ubuntu.com/) | 尋找各項產品的教學、操作指南與參考文件。 |
| [Ubuntu Project Documentation](https://ubuntu.com/project/docs/) | 了解 Ubuntu 的開發流程、社群治理，以及如何貢獻套件、測試、翻譯與文件。 |
| [Ubuntu Wiki](https://wiki.ubuntu.com/) | 查找 Ubuntu 社群團隊、開發規劃與協作資料，不只是使用教學。 |

Ubuntu Wiki 的部分內容可能較舊，使用指令前請確認適用的 Ubuntu 版本；產品操作優先參考目前的官方文件。

## 社群討論與開發協作

| 網站 | 主要用途 |
| --- | --- |
| [Ubuntu Discourse](https://discourse.ubuntu.com/) | Ubuntu 社群討論、公告與開發交流。 |
| [Ask Ubuntu](https://askubuntu.com/) | 社群問答網站，適合搜尋安裝與使用問題；不是正式的 bug 回報平台。 |
| [Launchpad](https://launchpad.net/) | 開發協作平台，提供問題追蹤、原始碼託管、翻譯，以及 Ubuntu PPA 等功能。 |

遇到使用問題可以先查文件與 Ask Ubuntu；確認是 Ubuntu 套件的 bug 時，再依套件的回報指引使用 Launchpad。
Launchpad 上也有第三方專案與 PPA，並非所有內容都由 Canonical 維護。

## 套件、版本與安全資訊

| 網站 | 主要用途 |
| --- | --- |
| [Ubuntu Packages](https://packages.ubuntu.com/) | 查詢 Ubuntu 套件的版本、相依關係與包含的檔案。 |
| [Ubuntu Releases](https://releases.ubuntu.com/) | 下載 Ubuntu 安裝映像與查看相關校驗檔案。 |
| [Ubuntu Security](https://ubuntu.com/security) | 查閱安全公告（USN）、CVE 資訊與安全維護服務。 |

## 應用商店與帳號

| 網站 | 主要用途 |
| --- | --- |
| [Snapcraft](https://snapcraft.io/) | 搜尋 Snap Store 的應用程式，以及查閱 Snap 製作與發佈文件。 |
| [Charmhub](https://charmhub.io/) | 搜尋 Juju 使用的 charms 與 bundles。 |
| [Ubuntu One](https://login.ubuntu.com/) | 多個 Ubuntu 與 Canonical 服務共用的登入帳號入口。 |

Snap 與 charm 可能由 Canonical 或第三方發佈，安裝前請確認發佈者與維護狀態。
